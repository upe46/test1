# 自動 Git コミット & プッシュ

このワークスペースでファイルを作成・変更・削除したら、作業の最後に
ユーザーへの確認なしで以下の手順を必ず自動実行すること。

```powershell
git add .
git commit -m "<変更内容を表す簡潔な日本語メッセージ>"
git push
```

- コミットメッセージは変更内容に合わせて具体的に書く（例: "UIの変更", "ボタンの色を修正"）。
- 1回の依頼で複数ファイルを変更した場合は、最後にまとめて1回コミットする。
- 変更がない場合（`nothing to commit`）はコミット・プッシュを行わない。
- push に失敗した場合はエラー内容をユーザーに報告する。
- 完了後、GitHub Pages への反映に数分かかる旨を一言伝える。
